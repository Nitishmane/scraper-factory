A run parses each provider's channel lineup, scrapes GUIDE_MAX_CHANNELS channel pages through the shared collector, converts Eastern airtimes to UTC locally, and stores rows in SQLite. The ranker joins guide rows with the Philo catalog and TMDB, scores every title, and keeps the top 10 of each kind. make publish upserts those 20 entities into Port's Context Lake; the webapp reads them at request time and links each card to its Philo record page.

2 · The fetch / extract relay split

One robot grabs the live page; a different robot is only allowed to read a saved copy.

Bright Data policy blocks collector runs against streaming-media domains (confirmed by their support, 2026-08-22, who endorsed this workaround). So scraping is a two-product pipeline: the Web Unlocker fetches the live page and archives it under fixtures/relay/, then the collector extracts from that tunneled copy. Two wins fall out for free — the code always tries a direct collector run first (so if the policy ever lifts, the relay disappears by itself), and every scrape's input HTML is archived, making drift investigations replayable byte-for-byte.

Two independent triggers feed one idempotent /heal endpoint: the inline detector (the reflex, seconds) and the SigNoz alert (the immune system, ~5 min, and the only thing that catches a pipeline that died entirely). Heal sends a plain-language description of the symptom to Bright Data, which proposes a fix and a preview. The Verifier is ordinary deterministic code: it diffs that preview against a frozen fixture. Pass promotes; fail rejects, marks the scraper broken, and escalates to a human. Nothing is ever promoted without a passing fixture diff.

The same doctrine as the heal loop, applied to shipping features. An operator's feature request becomes a requirement entity; a locally-run Claude Code edits a scratch clone (file tools only; fixtures/, verifier.py, and the drift thresholds are off-limits), and deterministic code opens the PR. GitHub Actions runs only no-AI checks, a human merges, and the deploy workflow ships to Vercel and records a factory_deployment back in Port. The builder runs locally on purpose: no Anthropic credentials leave the operator's machine. The human merge and the deterministic CI stay the promotion gates.

Every "traced" node above emits an OpenTelemetry span to SigNoz — even Port's automation calling /heal shows up as a span, because the service runs under opentelemetry-instrument. See the platform page for the full signal list.
